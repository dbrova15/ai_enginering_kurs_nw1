# Історія промптів RAG

## v2

- Називає точну модель або маркування компонента, якщо питання стосується його ідентифікації, а наданий чанк підтверджує зв’язок. Відповідь має цитувати цей чанк і позначати альтернативні моделі як альтернативи.
- Коли джерело підтверджує лише тип, відповідь наводить тип. Якщо питання прямо просить модель, але є лише часткові відомості, відповідь зазначає це в `limitations`.
- Профіль `config/hw2-v2.json` вмикає цей промпт. Для погодженого платного прогону потрібно додати `"generator_prompt": "prompts/rag/v2/system.txt"` до локального платного профілю. Типовим для порівняння є `v1`. Якість `v2` ще не виміряно.

## v1

- Початкова версія для ДЗ2: відповіді лише з наданого контексту, claims із chunk IDs, часткова відповідь та явна відмова.
- Окремі правила для недовірених інструкцій, схожих моделей і конфліктів версій.
- Прикладів із тестсету немає. Якість ще не виміряна; це початкові правила, а не доведене покращення.
