# Друга sampling-конфігурація — 26.10.2026

## Мета й умови

Перевірити, як зміна `temperature` впливає на якість витягування Schema v2. Порівнюються A: `temperature=0`, `top_p=1` та B: `temperature=0.7`, `top_p=1`. Змінюється один параметр; моделі, тексти, обидва промпти, golden та правила оцінювання збережено.

Моделі: прямий OpenAI API `gpt-4o-mini` і локальна Ollama `llama3.2:3b`. Для B виконано чотири нові прогони: кожна модель × кожен промпт, по тих самих 30 статтях. Додаткових probes, warmup-викликів або автоматичних повторних експериментів не виконувалося.

Метрики: accuracy кожного з восьми полів, їх середнє aggregate accuracy, micro precision/recall/F1 списків і валідність до/після repair. Якість оцінюється на тих самих 10 approved golden ID. Друга конфігурація змінює випадковість генерації; стабільне покращення наперед не припускається.

## Бюджет і виконання

Перед OpenAI-прогонами користувач підтвердив бюджет до **$0.15**. Попередня оцінка за usage baseline — $0.020095 на 60 первинних викликів, без додаткових repair/retry.

За [тарифом GPT-4o mini](https://developers.openai.com/api/docs/models/gpt-4o-mini), перевіреним 26.10.2026: $0.15 за мільйон вхідних і $0.60 за мільйон вихідних токенів. Фактичний usage нових запусків: **121862 вхідні + 3078 вихідні токени**. Оцінена вартість:

```text
(121862 × 0.15 + 3078 × 0.60) / 1000000 = $0.0201261
```

Це оцінка за повним тарифом input, без можливої знижки cached input, а не рахунок провайдера. Облік: [JSON бюджету](sampling_t07_openai_cost_20261026T095749556447Z.json). Підтверджено 60 HTTP-відповідей 200 із відомим usage; додаткових HTTP-повторів не було. Перед кожним запитом перевірявся резерв витрат проти дозволених $0.15; для невідомого usage передбачався консервативний резерв.

Для локальної Ollama зовнішніх API-платежів немає; обладнання й електроенергія не оцінювалися. Значення провайдера й sampling перевизначалися лише в процесах запуску: постійні `.env` та `main.py` не змінювалися.

## Межі висновку

На цих вимірюваннях `temperature=0.7` не дає послідовного покращення: один результат зріс, два знизилися, один не змінився. Це один прогін на комбінацію та лише 10 golden-документів; статистичної переваги або production-рекомендації ці результати не доводять.

Метрики списків використовують строгі канонічні значення без виправлення aliases чи регістру. Валідність JSON не означає правильності фактів. Окремий cold-start benchmark не виконувався; час у JSONL може включати завантаження локальної моделі, retry, repair та технічний облік OpenAI-запитів. Цей документ не подає latency як steady-state benchmark і не замінює підсумковий `REPORT.md` з аналізом помилок та рішенням автора.
