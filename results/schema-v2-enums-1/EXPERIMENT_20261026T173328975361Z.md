## Бюджет і облік

Усі 120 OpenAI HTTP-запитів мають usage: 270244 input / 5819 output tokens. Оцінка `(270244 × 0.15 + 5819 × 0.60) / 1_000_000 = $0.044028`, менше дозволених $0.25. Тарифний snapshot від 26.10.2026: input $0.15/1M, output $0.60/1M, [джерело](https://developers.openai.com/api/docs/models/gpt-4o-mini); кеш-знижки не застосовувались. Це оцінка, не рахунок OpenAI. Ollama має $0 зовнішніх API-витрат, але обладнання й електрика не оцінені.

Операторський transport перевіряв перед кожним OpenAI-викликом залишок бюджету й резервував консервативну оцінку вартості: UTF-8 байти запиту + 8192 службових токени та максимум 512 output tokens за тарифним snapshot. Після відповіді резерв замінювався фактичним usage; для невідомого usage залишався б у бюджеті. На завершенні невідомий резерв дорівнює нулю. Це захист конкретного операторського запуску; звичайний `main.py` грошового ліміту не реалізує.

Повний ledger, порядок, 30 ID/input hashes, хеші промптів, статуси восьми прогонів і кожний платний HTTP-виклик: [matrix manifest](matrix_20261026T173328975361Z.json). [Перевірка цілісності](verification_20261026T173328975361Z.json) підтверджує незмінність 48 захищених історичних файлів, 240 legacy-відповідей, відсутність ключів у нових JSONL та узгодженість метаданих/usage. Probe-запити сюди не входять.

## Відтворення

Спочатку налаштувати ключ OpenAI й запустити Ollama з наявною llama3.2:3b та `OLLAMA_CONTEXT_LENGTH=16384`. Не переносити цей дозвіл на наступний платний повтор: для нього потрібно окремо погодити бюджет. Код нижче описує матрицю, а не виконувався вдруге:

```powershell
$env:OPENAI_MODEL='gpt-4o-mini'
$env:OLLAMA_MODEL='llama3.2:3b'
$env:MAX_TOKENS='512'
$env:TOP_P='1'
$env:MAX_RETRIES='0'
$env:REQUEST_TIMEOUT_SECONDS='180'
foreach ($provider in @('openai', 'ollama')) {
    $env:LLM_PROVIDER=$provider
    foreach ($temperature in @('0', '0.7')) {
        $env:TEMPERATURE=$temperature
        foreach ($prompt in @('v1', 'v2')) {
            python main.py $prompt
        }
    }
}
```
